# Shiny output binding for safePivot

Shiny output binding for safePivot

## Usage

``` r
safePivotOutput(outputId, width = "100%", height = "600px")
```

## Arguments

- outputId:

  Output variable name.

- width:

  Width of the widget. e.g. "100%", "400px" or "80vh"

- height:

  Height of the widget.

## Value

A Shiny widget output object.
